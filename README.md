# Variable-Speed-Polishing-System-
Intelligent Control and Development of a Variable-Speed Polishing System

Overview

This project involved the design, fabrication, and experimental evaluation of a variable-speed polishing system for metallographic sample preparation. The machine incorporated a variable frequency drive (VFD) for adjustable rotational speed and a semi-automatic cooling system.

The objective was to investigate the relationship between operating conditions and polishing performance while developing a functional machine using locally sourced materials and fabrication techniques.

Engineering Design

Mechanical design and modelling were carried out using Fusion 360. The development process involved component selection, fabrication, machining, assembly, and hardware integration.

Additive manufacturing was also explored through the design of a 3D-printed polishing disc clamp. However, the prototype did not adequately secure the sample and was not incorporated into the final system. This highlighted the importance of functional validation when applying additive manufacturing to mechanical components.

Experimental Investigation

The machine was evaluated using aluminium and mild steel samples, with rotational speeds varied through the VFD.

Performance tests included:

* Material removal rate
* Surface finish
* Vibration
* Noise
* Temperature

The experimental observations indicated that material removal rate generally increased with rotational speed, although some exceptions occurred. Noise and temperature also increased as speed increased, while vibration remained relatively steady between 200 and 800 RPM, with some spikes at higher speeds.

These observations motivate further quantitative investigation of the relationships between operating parameters and process performance.

Computational Extension

This repository will extend the original experimental work through Python-based analysis of the available data.

The planned analysis will investigate how rotational speed relates to recorded performance indicators, using data processing, visualization, and quantitative comparisons to identify trends and limitations.

The aim is to complement physical experimentation with computational analysis and develop a more systematic approach to evaluating manufacturing-process performance.
