Variable-Speed-Polishing-System
Intelligent Closed-Loop Control for Variable-Speed Metallographic Polishing

Computer-vision surface scoring + Kalman-filter sensor fusion + score-driven spindle speed control, extending my final-year polishing machine (VFD-driven, built from locally sourced mild steel).

The Background 
My Undergraduate final-year project was a variable-speed metallographic polishing machine: VFD-driven, locally fabricated from mild steel, finishing aluminum and cast iron specimens well. Compared with manual fixed-speed polishing it cut polishing time by 30% and cost far less than imported units.

That machine is an open-loop system, where surface finish is judged with the eye. This repo adds the missing sense - estimate - control layer in software.
